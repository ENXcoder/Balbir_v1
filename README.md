# 🤖 Beta Automation - Discord Admin Bot

**Beta Automation** is a powerful and customizable Discord bot designed primarily for server admins. It includes both essential moderation features and fun or special admin-only commands. More features—including server nuker commands—are coming soon!

---

## 🚀 Features

### 🛡️ Admin Utilities:
- `!help` –Basic commands can be seen.
- `kick` – Remove members from the server.
- `ban` – Permanently ban users.
- `timeout` – Temporarily mute users.
- `clear` – Bulk delete messages in a channel.
- `announce` – Send announcement messages in a styled format.

### 🎮 Fun & Special Commands (Admin-Only by Discord User ID):
> These are restricted to specific admin user IDs coded inside the bot.
- `!tdr` – Fun commands can be seen.
- `ddos` – Simulated fake DDoS attack (for fun).
- `spam_pm` – Spam a user's DMs.
- `spam_server` – Spam user mentions in server channels.
- `tag_all` – Repeatedly tag `@everyone` in chat.

### 🔥 Upcoming:
- Full server nuker suite (use with caution!)
